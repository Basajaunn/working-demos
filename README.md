## Password Strength Checker

This is a python program which allows users to test their password against a list of the 10,000 most common passwords according to [Sec Lists](https://github.com/danielmiessler/SecLists/blob/master/Passwords/Common-Credentials/10k-most-common.txt). 
This was to demonstrate some of my python fundamentals as well as cybersecurity knowledge.

#### Some information about the project:
- Imports regex and getpass
- Opens and reads the passlist.txt file
- Hides password input by user
- Checks for length, complexity, and repeating characters
